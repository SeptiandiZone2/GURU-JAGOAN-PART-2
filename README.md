# Guru Jagoan AI v2.0 — SuperApp Administrasi Guru & Kurikulum Nasional (Next.js + Tailwind CSS)

Aplikasi terpadu hasil penggabungan dan peningkatan dari:
1. **Guru Jagoan AI (Base App)**: Racik Soal HOTS AI, Modul Ajar + 8 Perangkat Pendukung (LKPD, Bahan Ajar/Ringkasan, Icebreaker, Rubrik, Roleplay, Slide Presentasi PPT, Analisis Miskonsepsi Siswa, Surat Wali Murid), dan Modul Projek P5 / Kokurikuler.
2. **RPP Pembelajaran Mendalam (Deep Learning) & Insersi Isu Nasional**: Sintaks *Mindful (Berkesadaran), Meaningful (Bermakna), Joyful (Menggembirakan)* dengan tahapan *Memahami, Mengaplikasi, Merefleksi*, mendukung **Sekolah Umum (PAUD, SD, SMP, SMA, SMK)** & **Madrasah Kemenag (RA, MI, MTs, MA, MAK)**, **8 Dimensi Profil Lulusan**, **Panca Cinta Madrasah**, serta **Insersi Isu-Isu Prioritas Nasional** (Literasi, Numerasi, Koding & AI, Anti Perundungan, Anti Korupsi, Pendidikan Kebencanaan, 7 Kebiasaan Anak Indonesia Hebat, Koperasi Merah Putih, dll.).
3. **Generator KKTP Kurikulum Nasional**: Analisis Kriteria Ketercapaian Tujuan Pembelajaran berbasis **Taksonomi SOLO** (*Uni-structural, Multi-structural, Relational, Extended Abstract*) & Deep Learning lengkap dengan **Tabel Interval Nilai Rapor** (0-40%, 41-65%, 66-85%, 86-100%), mendukung upload dokumen CP/ATP (`.docx`/`.txt`) maupun generate otomatis dengan AI.
4. **Generator Administrasi Guru Lengkap**:
   - **Alur Tujuan Pembelajaran (ATP)** & Pemetaan CP-TP
   - **Program Tahunan (PROTA)**
   - **Program Semester (PROMES)**
   - **Instrumen Asesmen Diagnostik (Kognitif & Non-Kognitif)**
   - **Jurnal Agenda Mengajar & Refleksi Guru**
   - **Kartu Soal & Kisi-Kisi Penulisan Soal Supervisi**

## Cara Menjalankan Aplikasi

1. Buka terminal di folder `d:\APP GEMINI\GURU JAGOAN PART 2`
2. Jalankan perintah berikut:
   ```bash
   npm install
   npm run dev
   ```
3. Buka browser di alamat `http://localhost:3000`
4. Klik tombol **"Atur API Key AI"** di pojok kanan atas untuk memasukkan **Gemini API Key** Anda (atau simpan di file `.env.local` dengan nama `GEMINI_API_KEY=...`).
